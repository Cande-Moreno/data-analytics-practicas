RetailPro – Proyecto de Análisis de Datos

Descripción del proyecto

RetailPro es un proyecto de análisis de datos orientado a transformar los registros comerciales en información útil para la toma de decisiones.

El objetivo es analizar el comportamiento de las ventas, los productos y los clientes para identificar patrones y detectar factores que puedan explicar variaciones en el desempeño comercial.

Objetivo del análisis

Convertir los registros de ventas, clientes, productos y categorías en información confiable que permita identificar oportunidades de mejora y orientar las decisiones del área comercial.

Herramientas utilizadas

SQL Server: almacenamiento, consulta y análisis de datos.

SQL: extracción y transformación de información mediante consultas.

Power Query: limpieza y preparación de datos.

Power BI: creación de reportes y dashboards.

DAX: desarrollo de medidas e indicadores para el análisis.

Estructura del proyecto

Archivo

Descripción

ventas_tech_db.sql

Script para crear y cargar la base de datos Ventas_Tech_DB.

m4_consultas_negocio.sql

Consultas SQL para realizar análisis comerciales, como resumen mensual, ranking de productos y clientes recurrentes.

m5_consultas_joins.sql

Consultas para relacionar las tablas de ventas, clientes, productos y categorías mediante JOIN.

Cómo ejecutar el proyecto

Instalar Microsoft SQL Server y SQL Server Management Studio (SSMS).

Abrir y ejecutar ventas_tech_db.sql para crear y cargar la base de datos.

Verificar que se haya creado correctamente Ventas_Tech_DB.

Ejecutar m4_consultas_negocio.sql para obtener los indicadores y rankings comerciales.

Ejecutar m5_consultas_joins.sql para realizar consultas de relaciones entre tablas.

Revisar los resultados obtenidos en SQL Server Management Studio.

Resultados esperados

El proyecto busca facilitar el análisis del desempeño comercial mediante consultas SQL, indicadores y visualizaciones que permitan detectar patrones, oportunidades y aspectos que requieren mayor investigación.
